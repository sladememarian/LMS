## Generating sample users / transactions / tickets
Run the app (`java -cp build/classes/java/main ir.ac.kntu.Main`) and:
- Sign up + log in to create Guest personas (stored in `persona_secure.json`).
- Charge a wallet / extend a loan to create Finance transactions
  (`finance_secure.json`).
- Create a ticket in Support to populate `support_tickets.json`.
The repo's `.gitignore` excludes all these runtime stores so they never pollute
version control.
